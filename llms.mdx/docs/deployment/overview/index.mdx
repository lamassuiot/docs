# Deploy Lamassu (/docs/deployment/overview)



You can run Lamassu on your own Kubernetes cluster, deploy a prebuilt image from AWS Marketplace or consume the platform as a managed service.

Choose a model [#choose-a-model]

| Model                   | Recommended for                                            | Who operates the infrastructure | Starting point             |
| ----------------------- | ---------------------------------------------------------- | ------------------------------- | -------------------------- |
| Kubernetes self-managed | Production, regulated environments and custom deployments  | Your team                       | Helm or Fastlane           |
| AWS Marketplace         | Evaluation or a dedicated deployment inside an AWS account | Your team                       | Preconfigured image on EC2 |
| SaaS                    | Teams that want to use the platform without operating it   | Lamassu                         | Managed subscription       |

Just want to evaluate the platform? [#just-want-to-evaluate-the-platform]

Use [Fastlane](/docs/deployment/self-hosted/fastlane) to bring up PostgreSQL, Keycloak, RabbitMQ and Lamassu on a Kubernetes cluster through a single flow. It is intended for labs, demos and bootstrap; for production, configure dependencies and Helm values explicitly.

After deployment [#after-deployment]

Once the console is available, continue with [Create your first CA](/docs/platform/pki/quickstarts/create-certificate-authority). That quickstart verifies the cryptographic engine and issuance work correctly.
