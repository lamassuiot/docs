# [VA] Validación de Certificados (/docs/pr-preview/pr-20/manual/servicios-core/validation)



Validación de certificados – VA [#validación-de-certificados--va]

Lamassu ofrece dos mecanismos complementarios para validar el estado de los certificados emitidos por la plataforma:

* `OCSP`, para consultas online y en tiempo real del estado del certificado.
* `CRL`, para distribución y consulta offline de listas de revocación.

En el menú lateral del módulo `VA` encontrarás cada capacidad documentada en su propia página.
