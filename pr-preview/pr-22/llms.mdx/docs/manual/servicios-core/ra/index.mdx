# [DMS] Device Management Service (/docs/pr-preview/pr-22/manual/servicios-core/ra)



Device Management Service [#device-management-service]

El **DMS (Device Management Service)** es el componente de Lamassu IoT que actúa como Autoridad de Registro (RA) frente a los dispositivos. Cada DMS recibe las solicitudes de certificado, valida la identidad del solicitante según las políticas configuradas y encarga la emisión a la CA asignada. El resultado es un canal de aprovisionamiento controlado e independiente por flota, línea de producto o entorno.

En la práctica, cada DMS representa un punto de entrada diferenciado: tiene su propia CA de enrolamiento, sus propias reglas de autenticación y su propia ventana de renovación. Una organización puede operar varios DMS en paralelo - por ejemplo, uno para dispositivos de campo y otro para pasarelas internas - con políticas completamente distintas en cada caso.

Antes de empezar [#antes-de-empezar]

Para crear un DMS es necesario que exista al menos una CA activa en la plataforma, ya que el DMS requiere seleccionar una CA de enrolamiento. El usuario debe disponer del rol de administrador PKI o de permisos equivalentes sobre el módulo DMS.

Panel de DMS [#panel-de-dms]

El panel lista todos los DMS configurados en la plataforma. Cada entrada muestra el nombre del DMS, el protocolo de enrolamiento activo y la CA de enrolamiento asignada. Desde el menú de opciones de cada DMS están disponibles las siguientes acciones:

| Acción                      | Descripción                                                                 |
| --------------------------- | --------------------------------------------------------------------------- |
| **Edit**                    | Modifica la configuración del DMS.                                          |
| **Go to DMS owned devices** | Abre el listado de dispositivos gestionados por este DMS.                   |
| **Show/Edit Metadata**      | Accede a los metadatos del DMS para usos avanzados.                         |
| **EST (RFC-7030)**          | Muestra los endpoints EST del DMS con su URL base y ejemplos de invocación. |
| **Delete**                  | Elimina el DMS y su configuración. Acción irreversible.                     |

Distribución de entidades de confianza [#distribución-de-entidades-de-confianza]

La sección **CA Distribution** controla qué certificados de CA recibe el dispositivo al consultar el endpoint de distribución de confianza del protocolo activo. Esta configuración es independiente del protocolo de enrolamiento: los parámetros tienen el mismo significado con independencia de cómo el dispositivo obtenga sus certificados.

| Parámetro                     | Descripción                                                                                                                                                      |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Include Lamassu System CA** | Incluye el certificado TLS del servidor Lamassu en la respuesta. Este es el certificado de extremo del servidor, no una CA - útil para *pinning* de la conexión. |
| **Include Enrollment CA**     | Incluye la CA emisora configurada en este DMS, es decir, la que firmará los certificados de dispositivo.                                                         |
| **Managed CAs**               | CAs adicionales distribuidas al dispositivo como anclas de confianza.                                                                                            |

Protocolos de enrolamiento [#protocolos-de-enrolamiento]

El DMS expone un protocolo de enrolamiento a los dispositivos. En la versión actual de Lamassu, el único protocolo soportado es **EST (RFC 7030)**. La configuración del protocolo y la guía de integración para dispositivos se encuentran en las páginas correspondientes.
