Antes de empezar [#antes-de-empezar]

Necesitas acceso a la consola de Lamassu IoT y permisos para administrar claves, autoridades y dispositivos. La instancia debe tener al menos un motor criptográfico configurado.

Si todavía no tienes una instancia, elige primero un [modelo de despliegue](/docs/deployment/overview).
