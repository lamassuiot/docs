Documentación de la plataforma Lamassu IoT

Gestiona la PKI y las identidades digitales de tus dispositivos: autoridades de certificación, claves, enrolamiento EST y validación, todo desde una única plataforma.

# 1. Encuentra la IP de tu interfaz principal
ip a
2: eth0: ... inet 192.168.1.101/24 ...
# 2. Despliega Lamassu con esa IP
curl -fsSL "https://raw.githubusercontent.com/lamassuiot/lamassu-helm/refs/heads/main/scripts/lamassu-fast-lane.sh" \
| bash -s -- \
-n \
--domain lamassu.mypki \
--sample-data \
-ip 192.168.1.101
# → clúster listo

Capacidades principales

Todo lo necesario para construir y operar la identidad digital de tu flota de dispositivos.

Jerarquía de confianza
Autoridades raíz e intermedias, propias o importadas.
Gestión de claves
Software, HSM PKCS#11 o KMS cloud, sin acoplarte a uno.
Emisión y validación
Emite desde consola o CSR; valida con OCSP y CRL.
Enrolamiento de dispositivos
EST automático para flotas, sin tocar cada dispositivo.
