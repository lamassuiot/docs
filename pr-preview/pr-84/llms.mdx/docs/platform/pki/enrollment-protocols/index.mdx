# Enrollment protocols (/docs/pr-preview/pr-84/platform/pki/enrollment-protocols)



Lamassu supports EST (Enrollment over Secure Transport), defined in [RFC 7030](https://www.rfc-editor.org/rfc/rfc7030.html#section-3.2.2). The DMS applies the enrollment policy and the configured CA issues the certificates.

| Core endpoint          | Purpose                                            |
| ---------------------- | -------------------------------------------------- |
| `GET /cacerts`         | Retrieve the CA certificates published by the DMS. |
| `POST /simpleenroll`   | Request an initial certificate using a CSR.        |
| `POST /simplereenroll` | Request a successor to an existing certificate.    |

See [EST (RFC 7030)](/docs/platform/iot-fleets/est) for client setup, authentication, request formats and optional server-side key generation.
