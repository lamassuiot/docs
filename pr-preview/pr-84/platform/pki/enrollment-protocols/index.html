Enrollment protocols

Request and renew certificates from a Lamassu CA.

Sin cambios en esta página

Lamassu supports EST (Enrollment over Secure Transport), defined in RFC 7030. The DMS applies the enrollment policy and the configured CA issues the certificates.

Core endpointPurpose
GET /cacertsRetrieve the CA certificates published by the DMS.
POST /simpleenrollRequest an initial certificate using a CSR.
POST /simplereenrollRequest a successor to an existing certificate.

See EST (RFC 7030) for client setup, authentication, request formats and optional server-side key generation.
